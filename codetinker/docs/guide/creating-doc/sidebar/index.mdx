Creating a sidebar is useful to:

- Group multiple **related documents**
- **Display a sidebar** on each of those documents
- Provide **paginated navigation**, with next/previous button

import DocCardList from '@theme/DocCardList';

## Default sidebar
If the `sidebarPath` is unspecified, Docusaurus automatically generates a sidebar for you, by using the filesystem structure of the `docs` folder:


```markdown title="sidebar.js"
export default {
  mySidebar: [
    {
      type: 'autogenerated',
      dirName: '.', // generate sidebar from the docs folder (or versioned_docs/<version>)
    },
  ],
};
```

## NavBar
To add item in navigation bar, just simply go to `docusaurus.config.ts`.

```ts title="docusaurus.config.ts"
themeConfig: {
    // Replace with your project's social card
    image: 'img/docusaurus-social-card.jpg',
    navbar: {
      title: 'Codetinker Handbook',
      logo: {
        alt: 'My Site Logo',
        src: 'img/logo.svg',
      },
      items: [
        {
          type: 'docSidebar',
          sidebarId: 'tutorialSidebar',
          position: 'left',
          label: 'Tutorial',
        },
        // highlight-start
        {
          type: 'docSidebar',
          sidebarId: 'your-sidebar-id',  // sidebar id in sidebar.js
          position: 'left',
          label: 'your-doc-name',
        },
        // highlight-end
        {
          href: 'https://github.com/facebook/docusaurus',
          label: 'GitHub',
          position: 'right',
        },
      ],
    },
}
```

then you can see your item in your navigation bar already. :D
